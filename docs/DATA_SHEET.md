# Паспорт данных

## Симулятор
- Назначение: проверка конвейера и объяснений на данных с **известной причиной**; не замена реальным данным.
- Структура: студенты × дисциплины × недели; формы контроля: зачёт, дифзачёт, экзамен, курсовая; З.Е., пререквизиты, допуск, пересдачи.
- Скрытые переменные (способности, мотивация, момент потери интереса, обратная связь) хранятся отдельно (`World.truth`) и в признаки и БД не попадают.
- Сценарии: S0 гладкий, S1 пороговая обратная связь, S2 сдвиг когорты, S3 смещение измерения по группе, S4 потери данных.
- Параметры подобраны по правдоподобию (провалов около 19%, отчислений около 14% за 4 семестра, допуск около 87%), не по статистике вуза.

## OULAD (адаптер)
- Открытый набор Open University Learning Analytics Dataset; лицензия, насколько известно, CC BY 4.0 (проверить на странице набора перед публикацией).
- Соответствие: модуль × презентация → дисциплина, клики → недельная активность (дни активности и клики), ТМА/СМА → контрольные точки, Pass/Distinction → успех, Withdrawn → отчисление.
- Нет оценок 2–5, ЕГЭ, З.Е.; адаптер проверен только на синтетическом файле в формате набора.
